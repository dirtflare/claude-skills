# usage-meter

Claude Code の入力欄の上に、**5時間** と **週間** のレート制限の残り使用量を表示する mod です。

```
5時間 ██████░░ 残り76.5% あと1時間30分   週間 █████░░░ 残り60% あと2日20時間
```

- 残量に応じて色が変わります (30%以下で黄、10%以下で赤)。
- 1行だけを使い、ボタンのない表示専用の帯です。
- 数値は API 応答が報告するレート制限 (サブスクリプション利用時のみ) です。セッション開始直後、最初の応答までは「最初の応答のあとに表示されます」と出ます。
- 入力欄の上の帯 (AbovePrompt) に加えて、同じ内容を「残り使用量」ペインにも出します。帯を描かない画面 (クラウドセッションを見ているアプリなど) ではペインで見てください。
- 残りが 50% / 30% / 10% を切ったとき、会話の中にお知らせを1回だけ出します (枠のリセットごとにまた出ます)。帯やペインを描かない画面でも見えます。
- `usage-meter` で現在の数値をテキストで表示し、ペインを開き直します。

## インストール

Claude Code のプロンプトで:

```
/plugin install usage-meter --marketplace dirtflare/claude-skills
```

シェルから:

```bash
claude plugin install usage-meter --marketplace dirtflare/claude-skills
```

このリポジトリで開いたセッションでは `.claude/settings.json` によって自動で有効になります。
