# HyperFrames 日本語運用ガイド

HyperFrames は **HTML で書いた画面をそのまま MP4 にする**フレームワーク。
タイムラインは HTML の `data-*` 属性で宣言し、ヘッドレス Chrome が
1フレームずつ撮影し、FFmpeg が MP4 に固める。同じ入力から必ず同じ映像が出る
(決定論的レンダリング)。ローカル完結なので、何本書き出しても課金はない。

**このスキルの役割は、上流スキル群の日本語の運用レイヤー。**
動画の設計・実装そのものは上流の `/hyperframes` が持っている。
このスキルは「入る前の準備」「ブランドの仕込み」「レシピの選び方」
「直し方」だけを担当する。

---

## 0. 鉄則

1. **動画制作は必ず `/hyperframes` から入る。** ルーターが依頼内容を読んで
   適切な専門ワークフローに振り分ける。ユーザーがワークフロー名を暗記する
   必要はない。このスキルから直接 HTML を書き始めてはいけない。
2. **セットアップが済んでいない状態でレンダリングを試さない。** §1 のゲートを先に通す。
3. **リテイクは一文ずつ。** 詰め込むと精度が落ちる (§4)。

---

## 1. セットアップゲート

動画制作の依頼を受けたら、まず導入済みか確認する:

```bash
bash .claude/skills/hyperframes-jp/scripts/setup.sh
```

未導入・不足があれば:

```bash
bash .claude/skills/hyperframes-jp/scripts/setup.sh --install
```

必要なものは **Node.js v22 以上** と **FFmpeg** の2つだけ。どちらも無料。
レンダリング用の Chrome Headless Shell (約115MB) は初回のみ自動取得される。

手順の詳細・OS別のコマンド・つまずきどころは
[references/setup.md](references/setup.md) を読む。

導入後に使えるようになる主なスラッシュコマンド:

| コマンド | 用途 |
|---|---|
| `/hyperframes` | **司令塔。** 必ずここから入る |
| `/faceless-explainer` | 顔出しなしの解説動画 (記事・ノート・トピックから) |
| `/music-to-video` | 曲を渡してビート同期の動画 |
| `/motion-graphics` | 10秒以下の短尺。数字カウントアップ、ロゴ演出、実績カード |
| `/talking-head-recut` | 既存の喋り動画に図解・テロップを重ねる |
| `/pr-to-video` | GitHub PR をレビュー用解説動画に |
| `/product-launch-video` | サイトURL や商品情報からプロモ動画 |
| `/embedded-captions` | 既存動画に字幕だけを付ける |
| `/slideshow` | プレゼン・ピッチデッキ (MP4 ではなく操作可能なデッキ) |
| `/general-video` | 上に当てはまらない自由な構成 |

これ以外に、ルーターが必要に応じて読み込むドメインスキル
(`hyperframes-core` / `-animation` / `-creative` / `-cli` / `media-use` 等) が入る。
**ユーザーはこれらを直接呼ばなくてよい。**

## 2. ブランドを仕込む (`frame.md`)

AI が作った動画が安っぽく見えるのは品質のせいではなく、
エージェントがブランドを知らないから世界の平均値を出してくるだけ。
色・フォント・トーン・**動き方**を先に渡せば解決する。

⚠️ **ファイル名は小文字の `frame.md`。** 上流の仕様は
`frame.md` → `design.md` → `DESIGN.md` の順で最初に見つかったものを読む。
大文字の `FRAME.md` はプリセットの*テンプレート*名でしかなく、
読み込み対象には入っていない。Linux では大文字だと無視される
(macOS は大文字小文字を区別しないので偶然動いてしまい、事故に気づきにくい)。
**必ず小文字で置く。**

作り方は3ルートある。詳細と実際のプロンプトは
[references/brand.md](references/brand.md):

- **自分のサイトから抽出** — 推測を禁止し CSS の実データから取らせ、
  最後に出典を言わせるプロンプトを使う (ハルシネーション対策込み)
- **同梱プリセットから選ぶ** — 13種のフレームプリセットが
  `.agents/skills/hyperframes-creative/frame-presets/` にローカルで入っている。
  各フォルダの `frame-showcase.html` を開けば見た目を確認できる
- **対話で作る** — サイトがなければ、普段使っている色・フォント・口調を伝えて作らせる

一度置けば、そのフォルダで作る動画すべてに自動適用される資産型の仕込み。
ブランドが複数あるならフォルダを分ける。

## 3. レシピを選ぶ

用途別の使い方・そのまま投げられる日本語プロンプト・注意点は
[references/recipes.md](references/recipes.md) に5つまとめてある。

| やりたいこと | レシピ |
|---|---|
| 過去記事・ノートを動画化する | 1. 解説動画 (`/faceless-explainer`) |
| 商品・イベントを告知する | 2. 音ハメ動画 (`/music-to-video`) |
| 実績・数字を1枚のカードで出す | 3. モーショングラフィックス (`/motion-graphics`) |
| 撮影済み動画に図解を重ねる | 4. トーキングヘッド (`/talking-head-recut`) |
| コードレビューを動画にする | 5. PR動画 (`/pr-to-video`) |

**最初の1本はレシピ3が最短。** 入力が一文で済む。

---

## 4. リテイクは一文で通す

HyperFrames の真価は1本目より2本目以降、つまり修正の場面に出る。
映像の専門用語 (イージング、キーフレーム) は一切使わない。
**見たままの不満と、欲しい状態だけを言う。**

実際に通る指示の例:

- 字幕の枠を外して、色の変化だけにして
- この文字が上の行と被ってるから、下に逃して
- 締めのカードは1枚にまとめて、最後は緑のバナーで止めて
- 図解は画面の左3分の1に寄せて

コツと、指示の粒度・検証の回し方は
[references/retake.md](references/retake.md)。

**1回の指示に修正を詰め込みすぎない。** 一文か二文で1テーマ、
返ってきたら次、のリズムが結局一番速い。

---

## 5. エラーが出たとき

赤い文字のエラーメッセージを**丸ごと**貼る。原因を特定して修正し、
再レンダリングまで回す。エラーを人間が解読する必要はない。

よくある詰まりどころ (FFmpeg 未導入、Node が古い、Chrome 未取得、
`frame.md` の大文字小文字、任意依存の whisper / TTS / BGM) の切り分けは
[references/setup.md](references/setup.md) の「トラブルシュート」に集約。

---

## 6. ターミナルが無理な場合

HeyGen 本体に組み込まれた **Video Agent** (app.heygen.com) が
ブラウザ完結の入り口。CLI もリポジトリもスキル導入も不要。
アバターに喋らせたい場合もこちら。

使い分けとプロンプトの型 (スタイル段落) は
[references/video-agent.md](references/video-agent.md)。

ざっくりした判断基準:

| 条件 | 選ぶもの |
|---|---|
| 無料で量産したい / 自動化に組み込みたい / ブランドをファイルで厳密に管理したい | ターミナル版 (このスキル) |
| アバターに喋らせたい / 今すぐ1本欲しい / 黒い画面を見たくない | Video Agent (要 HeyGen アカウント) |

---

## 7. 前提と限界

- **無料・商用利用可。** Apache 2.0。レンダリング回数課金なし。
  ローカル完結なので外部にデータを送らない
- **特定 AI 専用ではない。** Claude Code / Codex / Cursor / Gemini CLI 等、
  スキル対応のエージェントで同じスキル群が動く
- **向いていない用途がある。** 実写素材を細かく切り貼りする Vlog 的な編集は
  従来の編集ソフトの土俵。HyperFrames が強いのは解説・告知・実績報告・
  モーショングラフィックスといった**情報を伝える動画**
- **アバター生成だけは HeyGen アカウントが必要** (`/talking-head-recut` の
  アバター部分)。撮影済み動画に図解を重ねる使い方ならアカウント不要
